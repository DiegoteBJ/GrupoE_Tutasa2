Plan de Prueba: 150_GenerarHDRTransporte-CaminoFeliz.txt

(Prerequisito: debe haber guías en estado ADMITIDA con CDActualId != CDDestinoId,
 y que no estén ya en un HDRTransporte en estado PENDIENTE.)

(Empieza con el Menú Principal)
1- Botón                       "Generar HDR Transporte"

(Pantalla Generar HDR Transporte - servicioId 3: Fletes del Sur S.R.L., CD CABA → CD La Plata)
2- Nro. Servicio de Transporte 3
3- Botón                       "Buscar"
4- Empresa Transporte resultado "Fletes del Sur S.R.L."
5- Fecha/Hora Salida resultado  "09/06/2026 20:30"
6- Ruta resultado               "CD CABA - CD La Plata"
7- Lista encomiendas pendientes <guías en estado ADMITIDA, que no estén en ningún HDRTransporte en estado PENDIENTE>
8- Seleccionar todas las guías de la lista
9- Botón                        "Confirmar"
10- Mensaje                     "HDR de transporte generado correctamente."
11- Botón                       "Aceptar"
12- Volver al menú principal

Verificaciones:
13- HDRTransporteEntidad.json - Debe existir una entrada nueva similar a:
    {
        "HdrTransporteId": <último id + 1>,
        "ServicioId": 3,
        "CDOrigenId": 1,
        "CDDestinoId": 8,
        "Estado": "PENDIENTE",
        "GuiaIds": [<ids de las guías seleccionadas>]
    }

14- GuiaEntidad.json - Las guías seleccionadas deben tener:
    {
        "Estado": "ADMITIDA"
    }

15- MovimientoEstadoGuiaEntidad.json - Debe existir una entrada nueva por cada guía similar a:
    {
        "MovimientoId": <último id + 1>,
        "GuiaId": <id de la guía>,
        "FechaMovimiento": "<fecha y hora de hoy>",
        "Estado": "ADMITIDA",
        "Ubicacion": "En CD: 1"
    }

16- CuentaCorrienteClienteEntidad.json - El registro de cada guía seleccionada debe tener:
    {
        "EmpresaTransporteId": 2
    }
